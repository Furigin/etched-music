⚙️ Настройки (GitHub-токен и репозиторий)
Токен хранится только в этом браузере (localStorage) и уходит напрямую в GitHub API. Используй fine-grained токен, ограниченный только репозиторием для музыки с правом Contents: Read and write — тогда в худшем случае рискуют только файлы этого репозитория.
