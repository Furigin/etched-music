# Etched Uploader

Простой сайт: перетаскиваешь аудиофайл → он сохраняется в твой GitHub-репозиторий → получаешь **постоянную прямую ссылку** для мода **Etched**.

GitHub доступен из РФ без VPN, ссылки не протухают, а тип файла Etched принимает — так что пластинки будут работать и на сервере, и у всех игроков.

## Что внутри

- `server.js` — бэкенд на Node/Express. Принимает файл и коммитит его в репозиторий через GitHub API. Токен лежит только на сервере, в браузер не попадает.
- `index.html` — страница с drag-and-drop и кнопкой «Копировать».
- `.env.example` — шаблон настроек.
- `package.json` — зависимости.

Отдаёт две ссылки: **jsDelivr** (CDN, быстрее и стабильнее из РФ — рекомендуется) и обычную **raw.githubusercontent.com**.

## Настройка (10 минут)

### 1. Создай репозиторий для музыки
На GitHub → **New repository** → имя, например `etched-music` → **Public** (обязательно, иначе raw/jsDelivr не отдадут файл) → Create.

### 2. Получи токен доступа
GitHub → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
- **Repository access** → Only select repositories → выбери `etched-music`.
- **Permissions → Repository permissions → Contents → Read and write**.
- Сгенерируй и **скопируй токен** (`github_pat_...`). Показывается один раз.

### 3. Установи зависимости
Нужен установленный [Node.js 18+](https://nodejs.org). В папке проекта:

```bash
npm install
```

### 4. Заполни настройки
Скопируй `.env.example` в `.env` и впиши свои значения:

```bash
cp .env.example .env
```

```
GITHUB_TOKEN=github_pat_ваш_токен
GITHUB_OWNER=ваш_логин
GITHUB_REPO=etched-music
```

> Если выкладываешь сайт в интернет — обязательно задай `UPLOAD_PASSWORD`, иначе кто угодно сможет заливать файлы в твой репозиторий.

### 5. Запусти

```bash
npm start
```

Открой **http://localhost:3000**, перетащи mp3 — получишь ссылку. Вставляй её в стол прожига (etching table) в Minecraft.

---

## Как это использовать в Etched

1. Залей трек через сайт, скопируй ссылку (лучше jsDelivr).
2. В игре открой **etching table**, вставь ссылку, запиши пластинку.
3. Готово. Ссылка постоянная — пластинка не «сломается» позже.

## Залить код в репозиторий Furigin/etched-music

Токен нужен только на твоей машине, поэтому пушишь ты сам (в чат его слать нельзя). Из папки проекта:

```bash
git init
git add .
git commit -m "Etched uploader"
git branch -M main
git remote add origin https://github.com/Furigin/etched-music.git
git pull --rebase origin main --allow-unrelated-histories   # если в репо уже есть README
git push -u origin main
```

При `git push` GitHub попросит войти (через браузер или менеджер учёток) — это нормально, токен вводить в команду не нужно.
`.gitignore` уже настроен так, что `.env` и `node_modules` в репозиторий **не попадут**.

## Публичный деплой (чтобы загружать могли другие)

Пока сайт крутится только на твоём `localhost:3000`, другие до него не достучатся. Чтобы дать доступ всем — разверни на бесплатном хостинге. Проще всего **Render** (в проекте уже лежит `render.yaml`):

1. Зайди на **render.com**, войди через GitHub.
2. **New → Blueprint** → выбери репозиторий `Furigin/etched-music` → Render сам увидит `render.yaml`.
3. В настройках впиши секретные переменные:
   - `GITHUB_TOKEN` — твой токен,
   - `GITHUB_OWNER` — `Furigin`,
   - `GITHUB_REPO` — `etched-music`,
   - `UPLOAD_PASSWORD` — **обязательно задай пароль**, иначе кто угодно завалит твой репозиторий файлами.
4. **Apply / Deploy**. Через пару минут получишь публичный адрес вида `https://etched-uploader.onrender.com`.
5. Раздай ссылку и пароль тем, кому можно загружать. Они открывают сайт, вводят пароль, кидают файл — получают ссылку для Etched.

Альтернативы: **Railway**, **Fly.io**, свой **VPS**. В проекте есть `Dockerfile` — подойдёт для любого контейнерного хостинга. Везде принцип один: переменные окружения задаёшь в панели хостинга, `.env` в git не коммитишь.

> ⚠️ На бесплатном тарифе Render сайт «засыпает» при простое — первое открытие после паузы может грузиться ~30 секунд. Для пары друзей это ок.

## Частые вопросы

**Файл не заливается — «GitHub: Bad credentials».**
Токен неверный/истёк или без права `Contents: Read and write` на этот репозиторий. Пересоздай токен (шаг 2).

**«GitHub: Not Found».**
Неверный `GITHUB_OWNER`/`GITHUB_REPO`, либо репозиторий не выбран в разрешениях токена.

**Etched пишет «Unsupported Content-Type».**
Заливай файлы с нормальным расширением (`.mp3`, `.ogg`, `.wav`). Сервис их и так проверяет, но на всякий случай.

**Большой файл не грузится.**
GitHub API не любит файлы больше ~50 МБ. Сожми трек или подними лимит в `.env` (`MAX_UPLOAD_MB`) на свой страх и риск.

**Лимиты.** GitHub — не файлопомойка. Для личной музыки в разумных объёмах всё ок; не заливай туда гигабайты.
